### Como instalar

1. Clique em **Baixar para Mac**, acima.
2. Abra o arquivo baixado e arraste o **Tiger Media Tools** para a pasta **Aplicativos**.
3. Na primeira vez, abra o **Terminal**, cole o comando abaixo e pressione Enter:
   ```bash
   xattr -cr "/Applications/Tiger Media Tools.app"
   ```
4. Abra o Tiger Media Tools, entre na sua conta e clique em **Instalar** nos aplicativos que quiser.

Pronto. As atualizações chegam pelo próprio Tiger Media Tools.

<sub>O comando do passo 3 libera só este app, uma única vez: ele ainda não tem o certificado pago da Apple. Dúvidas: fale com a equipe Tiger Media Tools.</sub>
